# 🐍 Snake Game

Este é um projeto simples e divertido do clássico **Snake Game**, desenvolvido com **HTML**, **CSS** e **JavaScript**. Nele, o jogador controla uma cobrinha que precisa comer a comida para crescer, 
mas sem encostar nas bordas do mapa — ou o jogo termina!

## 📱 Responsividade

O jogo é **responsivo**, ou seja, pode ser jogado tanto em computadores quanto em dispositivos móveis, se adaptando bem a diferentes tamanhos de tela.

## 🎮 Como jogar

- Use as **setas do teclado** (↑ ↓ ← →) para controlar a direção da cobrinha.
- Pegue a comida para crescer e aumentar sua pontuação.
- Não bata nas **paredes**! Se isso acontecer, o jogo será reiniciado.

## 🛠 Tecnologias utilizadas

- **HTML5**  
- **CSS3**  
- **JavaScript (puro)**
